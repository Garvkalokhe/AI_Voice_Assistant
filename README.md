# AI Voice Assistant

A Python-based voice-activated personal assistant that uses speech recognition, text-to-speech, APIs, and automation to perform common tasks through voice commands.

## Features

- Voice command recognition
- Text-to-speech responses
- Current time and date
- Weather information using OpenWeather API
- Latest news headlines using NewsAPI
- Open websites using voice commands
- Voice-based reminders
- Error handling for unrecognized commands and unavailable services
- Secure API key management using environment variables

## Technologies Used

- Python 3.12
- SpeechRecognition
- PyAudio
- pyttsx3
- Requests
- python-dotenv
- OpenWeather API
- NewsAPI
